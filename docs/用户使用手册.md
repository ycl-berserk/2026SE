# 学院学生综合服务与党团管理平台用户使用手册

本文档面向无技术背景用户，说明学生、学生骨干、辅导员和管理员如何分别在小程序端与 Web 端使用平台。平台分为两个入口：

- 小程序端：服务学生和学生骨干，提供通知查看、智能问答、资料下载、党团事务、证明申请、请假申请、学业分析、学生画像等功能。
- Web 端：服务辅导员和管理员，提供学生导入、通知发布、知识库维护、党团管理、申请审批、轮播图管理、反馈处理、系统设置等功能。

## 一、账号与权限说明

### 1. 角色说明

| 角色 | 使用入口 | 能做什么 |
| --- | --- | --- |
| 学生 | 微信小程序 | 查看通知、智能问答、下载文件、查看党团进度、提交证明/请假/党团申请、维护个人资料、查看学业分析等 |
| 学生骨干 | 微信小程序 | 拥有学生功能，并可处理分配给自己的普通通知反馈 |
| 辅导员 | Web 管理端 | 管理学生、发布通知、维护知识库和模板、审批申请、处理反馈、管理党团事务等 |
| 管理员 | Web 管理端 | 拥有辅导员全部功能，并可审批辅导员注册申请、管理系统设置等 |

### 2. 账号来源

- 学生和学生骨干不能自行注册。
- 学生和学生骨干账号必须由辅导员或管理员在 Web 端“学生管理”中导入数据库。
- 辅导员需要在 Web 端提交注册申请，等待管理员审核通过后才能登录。
- 管理员账号为系统内置账号：账号 `admin`，密码 `admin123`。

### 3. 端侧限制

- 学生和学生骨干只能登录小程序端，不能登录 Web 管理端。
- 辅导员和管理员只能登录 Web 管理端，不能登录小程序端。
- 小程序端不开放注册入口。如学生无法登录，请联系辅导员或管理员确认账号是否已导入。

## 二、小程序端使用说明

### 1. 学生登录

1. 打开微信小程序“学院学生服务平台”。
2. 进入登录页。
3. 在“学号”中输入自己的数字学号。
4. 在“密码”中输入辅导员或管理员提供的初始密码。
5. 点击“登录”。
6. 登录成功后进入首页。

注意事项：

- 学号只能输入数字。
- 如果提示“登录失败”或“账号不存在”，请联系辅导员确认账号是否已导入。
- 如果忘记密码，请联系辅导员或管理员重置。

### 2. 学生骨干登录

学生骨干与普通学生登录方式相同：

1. 打开微信小程序。
2. 输入学生骨干本人的数字学号和密码。
3. 点击“登录”。
4. 登录成功后进入首页。

学生骨干除普通学生功能外，还可以在“待处理反馈”中处理被分配的普通通知问题。

### 3. 首页使用

首页集中展示常用入口、轮播图、待办提醒、最新通知和常用下载。

常用操作：

1. 点击首页轮播图，可查看相关通知或知识资料。
2. 在首页搜索框输入关键词，可搜索平台内通知、知识库和功能入口。
3. 点击快捷入口，可快速进入“入党流程追踪”“思想汇报提交”“党团活动申请”等常用功能。
4. 点击“编辑快捷入口”，可调整首页常用入口。
5. 点击待办卡片，可进入对应页面查看未读通知、党团提醒、待处理汇报或反馈。
6. 点击“AI 助手”入口，进入智能问答。

### 4. 智能问答

智能问答用于咨询请假、证明、党团流程、通知、政策等常见问题。

操作步骤：

1. 在首页进入“AI 助手”。
2. 在输入框中输入问题，例如“我想请假怎么办”“入党积极分子需要提交什么材料”。
3. 点击发送。
4. 查看系统回答。
5. 如果回答下方显示“引用资料”，可点击引用卡片查看对应通知或知识内容。
6. 如果回答下方显示“相关入口”，可点击进入对应功能页面继续办理。

使用建议：

- 尽量用明确问题提问，例如“在校证明怎么申请”比“证明”更容易得到准确结果。
- 涉及正式政策时，以回答中引用的官方资料、通知或附件为准。

### 5. 通知与公众号信息

进入方式：底部导航栏点击“通知”。

常用操作：

1. 查看通知列表，未读通知会显示未读状态。
2. 在搜索框输入关键词，点击“搜索”查找通知。
3. 可选择“按时间”或“按相关度”排序。
4. 点击通知卡片进入详情。
5. 在详情页查看标题、发布时间、通知类型、正文和附件。
6. 如果通知来自公众号文章，点击“查看原文”打开公众号原文。
7. 如果有附件，点击“下载”打开附件。
8. 如对通知有疑问，可在“疑问反馈”中选择“普通问题”或“私密问题”，输入内容后提交。
9. 如需后续重点关注，可在列表中点击“置顶”；已置顶通知可取消置顶。

普通问题和私密问题区别：

- 普通问题可能由指定学生骨干先处理。
- 私密问题直接由辅导员处理，不会分配给学生骨干。

### 6. 学生骨干处理通知反馈

进入方式：首页待办“反馈”或“待处理反馈”页面。

操作步骤：

1. 进入“待处理反馈”。
2. 查看分配给自己的普通问题。
3. 阅读学生问题和对应通知标题。
4. 如果能解答，点击“回复处理”，填写回复内容并提交。
5. 如果问题需要老师处理，点击“上报辅导员”。

注意事项：

- 学生骨干只能处理分配给自己的普通问题。
- 私密问题不会展示给学生骨干。
- 涉及隐私、处分、心理健康、家庭情况等内容，应上报辅导员处理。

### 7. 知识库与政策查询

进入方式：首页搜索、服务页“政策知识库”，或底部“服务”中的相关入口。

常用操作：

1. 进入“知识库”。
2. 在搜索框输入关键词，例如“奖学金”“请假”“思想汇报”“宿舍调整”。
3. 点击分类标签筛选内容。
4. 点击知识卡片查看详情。
5. 查看回答摘要、适用标签、来源和正文内容。
6. 在“为你推荐”中查看系统根据年级、专业、党团阶段、近期行为推荐的资料。

### 8. 官方文件和模板下载

常见入口：

- 首页“常用下载”。
- 服务页“政策知识库”或“模板下载”。
- 知识库中的模板卡片。

操作步骤：

1. 进入“模板下载”或“知识库”。
2. 找到需要的文件，例如证明模板、请假条、活动预算表、简报模板、思想汇报模板等。
3. 点击模板卡片。
4. 系统下载并打开文件。
5. 按文件要求填写后用于线下提交或后续申请。

### 9. 党团事务流程追踪

进入方式：底部“服务” -> “入党流程追踪”。

可查看内容：

- 当前党团阶段。
- 当前步骤。
- 入党流程时间线。
- 阶段开始时间、结束时间和备注。
- 当前阶段注意事项和材料清单。

操作步骤：

1. 进入“入党流程追踪”。
2. 查看顶部个人信息和当前阶段。
3. 横向滑动流程条，查看完整阶段。
4. 查看“阶段信息”了解开始时间、结束时间和备注。
5. 查看“注意事项”了解下一步需要准备的材料。

如果阶段信息不正确，请联系辅导员在 Web 端更新。

### 10. 思想汇报提交

进入方式：底部“服务” -> “思想汇报提交”。

操作步骤：

1. 输入思想汇报标题。
2. 填写正文内容，正文可选。
3. 如需上传附件，点击“选择文件”，选择 PDF 或 Word 文件。
4. 点击“提交”。
5. 在“我的思想汇报”中查看审核状态。
6. 如被驳回，查看审核意见后按要求修改并重新提交。

### 11. 党团活动申请

进入方式：底部“服务” -> “党团活动申请”。

操作步骤：

1. 输入活动标题。
2. 填写申请事由。
3. 选择活动日期，日期可选。
4. 点击“提交”。
5. 在“我的申请”中查看状态和审核意见。

### 12. 电子证明申请

进入方式：底部“服务” -> “电子证明生成”。

操作步骤：

1. 点击“申请证明”。
2. 选择证明类型。
3. 填写证明标题，例如“在校证明申请”。
4. 填写申请理由。
5. 点击“提交申请”。
6. 在证明申请列表中查看状态。
7. 如被驳回，查看驳回原因后重新提交。

说明：

- 证明内容会根据学生基础信息和模板生成。
- 审批通过后，可按页面提示下载或查看证明文件。

### 13. 请假申请

进入方式：底部“服务” -> “请假审批流程”。

提交请假：

1. 进入“请假申请”。
2. 点击“发起请假”。
3. 填写请假标题。
4. 填写请假事由。
5. 选择开始日期和结束日期。
6. 填写联系电话。
7. 点击“提交申请”。

查看进度：

1. 回到“我的请假”列表。
2. 通过顶部标签筛选全部、待审批、已通过、已驳回等状态。
3. 点击申请卡片查看详情和审批记录。

### 14. 学业分析与预警

进入方式：底部“服务” -> “学业分析与预警”。

功能说明：

- 平台根据培养方案统计各课程模块已修学分、应修学分和剩余学分。
- 分析结果仅作为个人规划参考，不替代教务系统正式认定。

录入课程：

1. 进入“学业分析与预警”。
2. 在“添加课程”中输入课程名称。
3. 可填写学分。
4. 选择课程大类。
5. 点击“添加”。

批量导入：

1. 在“批量导入”中选择默认课程大类。
2. 将成绩单或已修课程整理成文本后粘贴到输入框。
3. 支持每行一门课，也支持“课程名,课程大类”“课程名,学分”“课程名,课程大类,学分”等格式。
4. 点击“批量导入”。
5. 导入后查看学分概览、未修课程和选修建议。

查看分析结果：

1. 在“学分概览”查看各模块已修、需修和剩余学分。
2. 点击某个模块查看未修必修课。
3. 查看专业模块中的个性化选修大类、选修指导和按学期建议。
4. 如课程录入错误，可在“已录入课程”中清空全部后重新导入。

### 15. 学生画像与个人资料

个人中心入口：底部导航栏“个人中心”。

可维护信息：

- 姓名。
- 学生身份/年级。
- 专业。
- 班级。
- 手机号。
- 邮箱。
- 政治面貌。
- 生源地。
- 宿舍。
- 个人介绍。
- 头像。

操作步骤：

1. 进入“个人中心”。
2. 点击“更换头像”可更改头像。
3. 修改个人资料字段。
4. 点击“保存资料”。
5. 如需退出账号，点击“退出登录”。

学生画像入口：

1. 在“服务”中进入“学生画像”。
2. 查看基本信息、个人简介和奖励荣誉。
3. 可在“添加荣誉”中填写获奖学期和获奖内容。
4. 点击“添加”保存。

### 16. 奖励荣誉查看

进入方式：服务页“奖励荣誉”或学生画像中的荣誉区域。

可查看内容：

- 荣誉名称。
- 获得者。
- 获奖级别。
- 获奖时间。
- 荣誉说明。

如发现荣誉信息错误，请联系辅导员在 Web 端修改。

## 三、Web 管理端使用说明

### 1. Web 端登录

适用角色：辅导员、管理员。

操作步骤：

1. 使用电脑浏览器打开 Web 管理端地址。
2. 在登录页选择“登录”。
3. 输入工号或管理员账号。
4. 输入密码。
5. 点击“登录”。

账号规则：

- 辅导员账号必须是数字工号。
- 管理员账号固定为 `admin`。
- 管理员密码为 `admin123`。
- 学生和学生骨干账号不能登录 Web 端。

### 2. 辅导员注册

操作步骤：

1. 打开 Web 管理端登录页。
2. 切换到“辅导员注册”。
3. 填写姓名。
4. 填写数字辅导员工号。
5. 填写手机号和邮箱，手机号、邮箱可选。
6. 设置密码，密码至少 6 位。
7. 再次输入确认密码。
8. 点击“提交注册申请”。
9. 等待管理员审核通过。
10. 审核通过后回到“登录”页，使用工号和密码登录。

注意事项：

- 辅导员工号只能填写数字。
- 管理员账号不能通过注册创建。
- 注册申请未审核通过前不能登录。

### 3. 管理员审批辅导员注册申请

适用角色：管理员。

操作步骤：

1. 使用 `admin/admin123` 登录 Web 管理端。
2. 在左侧菜单进入“系统设置”。
3. 打开“辅导员账户管理”。
4. 查看状态为“待审核”的辅导员账号。
5. 点击“通过”。
6. 系统提示确认后，再次确认。
7. 通过后，该辅导员可正常登录。

管理员还可以在该页面新增、编辑或删除辅导员账号。

### 4. 工作台

进入方式：左侧菜单“工作台”。

工作台用于快速查看系统运行概况和待处理事项。辅导员和管理员登录后可先查看工作台，再进入具体功能处理。

### 5. 个人中心

进入方式：

- 左侧菜单“个人中心”。
- 或右上角用户名下拉菜单“个人中心”。

可用于查看和维护当前登录账号信息。完成操作后，可通过右上角下拉菜单退出登录。

### 6. 学生管理

进入方式：左侧菜单“学生管理”。

用途：

- 导入学生或学生骨干账号。
- 查看学生基础信息。
- 按年级、专业、班级、身份筛选学生。
- 删除不再使用的学生账号。

单个导入学生：

1. 点击“导入学生”。
2. 在“单个导入”区域填写学号、姓名、初始密码、身份、学生身份/年级、专业、班级、手机号等信息。
3. 身份可选择“普通学生”或“学生骨干”。
4. 点击保存或导入。
5. 导入成功后，学生即可用学号和密码登录小程序。

批量导入学生：

1. 点击“导入学生”。
2. 点击“下载 CSV 模板”。
3. 按模板填写学生信息。
4. 点击“上传 CSV 批量导入”。
5. 查看导入结果。
6. 如果部分行失败，根据错误提示修改 CSV 后重新上传。

查询学生：

1. 在筛选区输入关键词、年级、专业、班级或身份。
2. 点击“查询”。
3. 点击“重置”可清空筛选条件。
4. 点击某行“查看”可查看学生详情。

注意事项：

- 学号必须是数字。
- 学生身份/年级建议填写为 `2023本`、`2022硕`、`2021博` 等格式。
- 删除学生账号后，该学生将无法登录小程序，请谨慎操作。

### 7. 通知发布

进入方式：左侧菜单“通知发布”。

用途：

- 创建学院通知。
- 上传通知附件。
- 按年级、专业、班级、身份定向投递。
- 设置普通问题由哪些学生骨干处理。
- 将重要通知同步到首页轮播。
- 下架已发布通知。

新建通知：

1. 进入“通知发布”。
2. 点击新建通知按钮。
3. 填写通知标题、摘要、正文、类型、标签等信息。
4. 如有附件，点击“上传附件”。
5. 如需显示在首页轮播，打开“首页轮播”相关选项。
6. 在“疑问反馈处理”中选择负责处理普通问题的学生骨干；未指定骨干时，普通问题由发布通知的辅导员处理。
7. 在“发布范围”中选择年级、专业、班级和身份。
8. 可先保存草稿。
9. 确认无误后点击“发布通知”。
10. 系统会按筛选条件投递给学生。

编辑和下架：

1. 在通知列表找到目标通知。
2. 点击“编辑”修改内容。
3. 未发布或草稿通知可继续发布。
4. 已发布通知可点击“下架”。

说明：

- 已发布通知编辑内容不会自动改变原投递人群。
- 学生端已收到的消息在第一阶段仍会保留。

### 8. 反馈处理

进入方式：左侧菜单“反馈处理”。

用途：

- 查看学生对通知提交的疑问。
- 筛选普通问题、私密问题。
- 按状态查看待骨干处理、待辅导员处理、骨干已处理、辅导员已处理等反馈。
- 回复并关闭反馈。

操作步骤：

1. 进入“反馈处理”。
2. 按类型、状态、通知 ID 查询。
3. 点击“查看”打开反馈详情。
4. 阅读学生问题、反馈类型、处理状态和处理日志。
5. 在回复框填写回复内容。
6. 点击“回复并关闭”。

处理建议：

- 私密问题由辅导员直接处理。
- 学生骨干上报的问题应由辅导员继续处理。
- 回复内容应清晰说明下一步操作或官方依据。

### 9. 知识库管理

进入方式：左侧菜单“知识库管理”。

知识库管理包含“资料管理”“模板管理”“分类管理”“智能治理”等区域。

#### 9.1 资料管理

用于维护学生端可搜索的政策、流程、问答和指南。

新增资料：

1. 进入“知识库管理” -> “资料管理”。
2. 点击“新增资料”。
3. 填写标题、摘要、分类、内容类型。
4. 选择发布方式：
   - 上传文件：上传 PDF、Word、Excel、PPT、图片、Markdown、HTML、CSV、ZIP 等资料。
   - 在线编排：直接编辑 Markdown 或 LaTeX 源文案。
5. 填写标签、适用年级、适用专业、政治面貌、党团阶段、场景编码、适用范围等信息。
6. 设置优先级。
7. 点击“保存”。
8. 在列表中点击“发布”，学生端才能看到。

常用维护操作：

- “编辑”：修改资料信息。
- “发布”：使资料对学生可见。
- “下架”：暂时不让学生端看到。
- “源文件”：下载在线编排源文件。
- “OCR校正”：人工修正文件解析或图片识别结果。
- “日志”：查看解析与索引日志。
- “版本”：查看历史版本并可回滚。
- “查重”：检测重复资料。
- “删除”：删除资料。
- “重建全文索引”：重新生成搜索索引。
- “下架过期”：批量下架已过期资料。

#### 9.2 模板管理

用于维护学生可下载的官方文件模板。

操作步骤：

1. 进入“知识库管理” -> “模板管理”。
2. 点击“新增模板”。
3. 填写名称、说明、分类。
4. 上传模板文件。
5. 填写格式、标签、适用年级、适用专业、政治面貌、党团阶段、场景编码和优先级。
6. 点击“保存”。
7. 根据需要点击“启用”或“禁用”。

#### 9.3 分类管理

操作步骤：

1. 进入“知识库管理” -> “分类管理”。
2. 点击“新增分类”。
3. 填写分类名称、编码、排序和状态。
4. 点击“保存”。
5. 后续可对分类进行编辑或删除。

#### 9.4 智能治理

可查看知识库资料数、模板数、行为事件、推荐日志、搜索次数、点击反馈等统计信息，并维护同义词组。

### 10. 党团管理

进入方式：左侧菜单“党团管理”。

包含“学生进度管理”“思想汇报审核”“党团活动审批”等功能。

#### 10.1 学生进度管理

用途：

- 查看学生当前党团阶段。
- 更新学生阶段和步骤。
- 批量导入学生党团进度。

更新单个学生进度：

1. 进入“党团管理” -> “学生进度管理”。
2. 按学生、阶段等条件筛选。
3. 找到学生记录。
4. 点击编辑或更新。
5. 选择当前阶段。
6. 可选择当前步骤。
7. 填写开始时间、结束时间、备注等信息。
8. 点击“保存”。

导入学生进度：

1. 点击“导入学生进度”。
2. 可选择“单条录入”或“文件/粘贴导入”。
3. 单条录入时填写学号、阶段、步骤、时间等信息后保存。
4. 批量导入时上传文件或粘贴表格内容。
5. 系统解析后只导入校验通过的数据。
6. 查看导入结果，如失败则按错误提示修改后重试。

#### 10.2 思想汇报审核

操作步骤：

1. 进入“党团管理” -> “思想汇报审核”。
2. 按状态筛选待审核、已通过、已驳回记录。
3. 点击“审批”或“查看”。
4. 阅读标题、内容、附件和提交信息。
5. 填写审核意见。
6. 点击“通过”或“驳回”。

#### 10.3 党团活动审批

操作步骤：

1. 进入“党团管理” -> “党团活动审批”。
2. 按状态筛选活动申请。
3. 点击“审批”或“查看”。
4. 查看活动名称、活动日期、申请事由等信息。
5. 填写审核意见或驳回原因。
6. 点击“通过”或“驳回”。

### 11. 请假审批

入口：

- 左侧菜单“待审批”。
- 左侧菜单“已处理”。

处理待审批请假：

1. 进入“待审批”。

3. 点击“审批”。

查看已处理记录：

1. 进入“已处理”。
2. 查看已经审批过的申请。
3. 点击详情可查看历史审批信息。

### 12. 证明审批

进入方式：左侧菜单“证明审批”。

操作步骤：

3. 点击“详情”查看申请理由和当前状态。
4. 对待审批申请点击“通过”。

### 13. 荣誉管理

## 五、常见问题

### 1. 学生为什么不能注册？

学生和学生骨干账号由辅导员或管理员统一导入，目的是保证学号、姓名、年级、专业等基础信息准确，避免重复账号和错误身份。

### 2. 学生登录失败怎么办？

请先检查学号是否只输入了数字、密码是否正确。如果仍无法登录，请联系辅导员确认账号是否已导入、身份是否为学生或学生骨干。

### 3. 辅导员注册后为什么不能立即登录？

辅导员注册后需要管理员审核。管理员审核通过后，辅导员才能使用注册的工号和密码登录。

### 4. 管理员忘记账号怎么办？

管理员账号固定为 `admin`，默认密码为 `admin123`。如部署后修改过密码，请联系系统维护人员处理。

### 5. 通知反馈应该选普通问题还是私密问题？

一般咨询选择“普通问题”。涉及个人隐私、家庭情况、心理健康、处分、困难认定等内容，应选择“私密问题”。

### 6. 学业分析结果是否等同于教务系统结果？

不是。学业分析仅作为个人规划和预警参考，正式学分认定、毕业审核和选课规则仍以学校教务系统和学院通知为准。

### 7. 知识库回答和 AI 回答哪个更权威？

优先以知识库引用资料、官方文件、通知原文和附件为准。AI 回答用于辅助理解，遇到重要事项应查看引用资料或咨询辅导员。

### 8. 学生信息或党团阶段不正确怎么办？

学生可先在个人中心检查本人资料。若学号、身份、党团阶段等关键数据不正确，请联系辅导员在 Web 管理端修改。
