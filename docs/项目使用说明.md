# 学院学生综合服务平台 · 使用说明

## 一、小程序端（学生用）

### 1. 怎么打开项目

把 `miniprogram-1/` 文件夹发给你之后：
1. 打开 **微信开发者工具**
2. 点 **"导入项目"**
3. 目录选这个文件夹，AppID 会自动填好（`wx73e5919653d4910a`）
4. 确定就行

> **注意**：如果提示"当前版本不需要 AppID"，选"使用 AppID"模式。开发者工具右侧"详情 → 本地设置"里勾上 **"不校验合法域名"**，不然请求会被拦。

### 3. 功能怎么用

#### 首页
- **顶部轮播图**：展示设置了轮播的通知或手动添加的轮播内容，点进去跳通知详情（有的是仅展示 无链接）
- **快捷入口**：入党流程追踪、思想汇报提交、请假审批等
- **待办统计**：未读通知数、待办截止提醒、待处理反馈（骨干身份可见）
- **最新通知**：最近 5 条通知
- **模板下载**：常用模板列表

#### 登录 / 注册
- 用学号和密码登录
- 如果还没有账号，点注册创建

#### 通知
底部 Tab 第二个标签就是通知列表。
- 列表展示所有已发布的通知标题和日期
- 点进去看详情，未读会自动标记已读
- 可以置顶/取消置顶通知
- 可以在通知详情里提交疑问反馈（分普通和私密两种）
- **如果通知正文是公众号文章链接**，底部会出现"查看原文"按钮，点进去直接打开文章

#### 党团事务
首页点"入党流程追踪"进去：
- 顶部显示当前阶段（入党申请人 → 积极分子 → 发展对象 → 预备党员 → 正式党员）
- 横向滚动展示所有阶段，当前阶段高亮
- 下方显示当前阶段的待办指引和参考材料
- 可以查看系统生成的提醒（比如"积极分子满3个月需提交思想汇报"）

**思想汇报提交**：
- 查看已提交的汇报列表及审核状态
- 提交新的思想汇报（标题 + 正文 + PDF/Word 附件）

**党团活动申请**：
- 查看已提交的活动申请
- 提交新的活动申请（标题 + 事由 + 活动日期）

#### 请假
首页点"请假审批流程"进去：
- 列表展示所有请假申请及状态
- 点"新建请假"填写表单提交
- 点详情查看审批进度和审核意见

#### 政策知识库
首页点"政策知识库"进去：
- 按分类浏览政策文章（党团流程、学籍事务、奖助资助、日常服务）
- 顶部搜索框可以搜标题和内容
- 点文章进详情页查看

**模板下载**：

- 常用 Word 模板（思想汇报模板、请假申请表等）
- 点"下载"自动下载并用小程序打开

**AI 智能问答**：

- 在知识库里可以问政策相关问题
- 系统会基于知识库内容回答，并标注引用来源
- 如果 AI 不可用，会退回到本地知识检索

#### 电子证明
首页点"电子证明生成"进去：
- 申请电子证明（选类型、填原因）
- 查看申请记录及审批状态
- **注意**：目前只做申请和审批流程，不会自动生成 PDF 文件

#### 学业分析（尚未全部完成）
首页点"学业分析与预警"进去：
- 查看各模块学分完成情况（通识模块、专业模块等）
- 显示已修/未修学分对比
- 显示缺失的课程
- 推荐本学期应选的课程
- 可以**手动录入已修课程**（每条填课程名、学分、类型）
- 支持**批量导入**：按照"课程名,学分,类型"的格式粘贴多行
- **注意**：不支持上传成绩单 PDF 自动解析，只能手动添加

#### 学生画像
首页点"学生画像"进去：
- 展示个人档案信息
- 可编辑联系方式、简介等
- 可以上传头像
- 可以管理荣誉奖项（增删改）

#### 个人中心
底部 Tab 第四个：
- 展示个人信息
- 修改密码
- 退出登录

#### 全局搜索
首页顶部搜索框：
- 搜索政策知识库文章
- 也可以切到"通知"分类搜索通知

#### WebView 页面（查看外部文章）
- 通知详情里点"查看原文"会打开公众号文章
- 文章在小程序内直接展示，可以点赞、评论、转发

### 5. 常见问题

**Q：打开后白屏 / 请求失败？**
A：检查开发者工具是否勾了"不校验合法域名"，以及 `utils/config.js` 里的 `BASE_URL` 是不是正确的服务器地址。

**Q：登录提示"账号不存在"？**
A：确认学号没错，上面表格里的 6 个账号都能用。

**Q：通知列表是空的？**
A：说明后端没返回数据会显示本地兜底数据（几条示例通知），不影响查看页面效果。

### 3. 功能概览

#### 仪表盘
展示统计数据，快速了解平台运行情况。

#### 审批管理
- **待审批**：需要你处理的请假申请列表，点进去可以审核通过或驳回
- **已审批**：已经处理过的记录

#### 通知管理
- **通知列表**：查看所有通知，可以编辑、发布、下架
- **发布通知**：
  - 填写标题、摘要、正文
  - 选择类型（教学/党团/就业/生活/其他）
  - 设置标签
  - 选择目标人群（按年级/专业筛选，空着就是全体可见）
  - 勾选"首页轮播展示"：发布后自动同步到首页轮播图（这里没完全做好）
  - 点击"发布"才会投递给学生，保存草稿不会
- **通知反馈**：查看学生对通知的疑问，骨干处理后辅导员可以查看
- 当前通知功能的投递人数指的是当前的测试用户数量，不是由发布范围所决定的

#### 轮播图管理
- 手动增删改首页轮播图
- 通知发布时勾选了轮播的话会自动创建，你也可以在这手动管理

#### 党团管理
三个 Tab：
1. **学生进度管理**：查看学生当前党团阶段，可以手动修改或批量导入
2. **思想汇报审核**：查看学生提交的思想汇报，通过或驳回
3. **党团活动审批**：审核学生的活动申请

#### 学生管理
- 查看所有学生信息
- 手动添加或 CSV 批量导入

#### 知识库管理
- 管理知识库文章、分类、模板
- 支持上传 PDF/Word/Excel/图片附件

#### 系统设置
仅管理员可见：角色权限管理、AI 配置等。

### 4. 常见问题

**Q：登录提示"账号或密码错误"？**
A：辅导员账号是 `10000001`，不是 `admin`。

**Q：发通知后学生看不到？**
A：检查是否点了"发布"（保存草稿不会投递），以及目标人群筛选条件是否正确。

**Q：勾选了轮播但首页没显示？**
A：通知发布时会自动同步到轮播图。如果是在编辑时勾上的，需要重新保存。
